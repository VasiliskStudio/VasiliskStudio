## Vasilisk Virtual Studio

Студия, где свой ИИ собирают, учат и запускают прямо на маке: текст, картинки, видео, музыка — модели как дорожки,
версии как клипы, всё на этом компьютере.

| Программа | Что это |
|---|---|
| **[⬇ Vasilisk Dev](https://github.com/VasiliskStudio/vasilisk-dev/releases/latest)** | Полная сборка для мака на Apple Silicon. Бесплатно до версии 1.0. |
| **[Vasilisk X](https://github.com/VasiliskStudio/vasilisk-x)** | Открытая часть под MPL 2.0: читай код, собирай, делай свою версию. |

Текущая версия — **0.9**.
